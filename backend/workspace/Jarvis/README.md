VoicePal is a voice assistant for personal use made using python libraries. It is designed to provide a conversational interface for users to interact with their devices. The application uses speech recognition and natural language processing to understand user input and generate responses.

The application consists of several modules, including audio recording and playback, natural language processing, and a main application logic module. The audio module uses libraries such as PyAudio and SpeechRecognition to record and recognize audio, while the NLP module uses libraries such as NLTK and spaCy to perform NLP tasks.

To use VoicePal, simply run the application and start speaking. The application will recognize your speech and generate a response. You can ask VoicePal to perform various tasks, such as setting reminders, sending messages, and making calls.

The application is still in development, and new features are being added regularly. If you have any suggestions or feedback, please feel free to contact us.

System Requirements:
- Python 3.8 or higher
- PyAudio
- SpeechRecognition
- NLTK
- spaCy
- PyTTSX3
